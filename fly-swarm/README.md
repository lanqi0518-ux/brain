# 永生蜂群 · Immortal Fly Swarm

灵感来源：Google Research × HHMI Janelia 首次完整绘制的**成年雄性果蝇全脑连接组**（166,000+ 神经元的 3D 神经形态重建）。

这是一个纯前端可视化沙盒：市值决定食物供应，蜂后交配繁衍，个体永不死亡——只是在饥饿时休眠，等待下一次进食。整个蜂群像一张会呼吸的神经网络，永远向外生长。

## 世界规则

| 规则 | 说明 |
|---|---|
| 食物容量 | `capacity = √(市值 / 1000)`，市值越高，同时存在的食物越多 |
| 食物再生 | 与容量成正比，每秒缓慢补充 |
| 蜂后 (♛) | 每 5–8 秒且能量 > 0.75 时与附近工蜂交配，产 2–4 枚卵，消耗 0.35 能量 |
| 卵 → 幼虫 → 成虫 | 6–10 秒孵化；当群体 > 30 时，新生个体有 3% 概率晋升为蜂后 |
| 永生 | 能量归零不会死亡，仅显著减速、变暗，进食即复苏 |
| 神经晕 | 邻近个体之间以低透明度连线，视觉上还原连接组的"呼吸感" |

## 运行

```bash
cd fly-swarm
python3 -m http.server 8080
# 打开 http://localhost:8080
```

或直接双击 `index.html`（合约拉取需要通过 http/https 访问 DexScreener API）。

## 功能

- **合约地址拉取**：粘贴 EVM 或 Solana 合约地址，调用 [DexScreener](https://dexscreener.com/) 公共 API 拉取流动性最高的交易对的市值 (`marketCap` 优先，回落到 `fdv`)。
- **手动市值**：直接输入 USD 数额，实时改变食物容量。
- **控制**：暂停 / 重置 / 一键补食。
- **HUD**：种群、世代、食物、蜂后数、卵数、市值。

## 文件

- `index.html` — 页面骨架与 HUD 面板
- `styles.css` — 深色玻璃拟态样式
- `swarm.js` — 全部模拟与渲染逻辑（Canvas 2D，无依赖）
